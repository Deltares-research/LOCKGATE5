Example: Simple lock with schematized wave
===========
This example demonstrates the capability of the KASGOLF code by applying it to an hypothetical scenario. An overview of the lock and lockgate can be found in the figure below. The simulation starts at time t=-6.0 [s] with a time step of 0.02 [s]. A wave arrives at location A at time t=0 [s] and propagates to B with the propagation velocity of the translatory wave (linear wave theory). it is assumed that there is no horizontal opening present underneath the gate.
